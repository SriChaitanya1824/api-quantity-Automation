# BUG-002: Flaky UI Test Clicked Navigation Before Dashboard Loaded

- Type: Representative project defect record, not a historical production incident.
- Initial Failure: Request creation test intermittently failed because `nav-create` was not visible.
- Investigation: Trace showed login request still in flight while test attempted navigation.
- Evidence: Browser screenshot showed loading state instead of dashboard.
- Why Not Product Defect: Manual login completed normally; API and UI eventually reached dashboard.
- Root Cause: Test did not wait on a user-visible loaded condition.
- Stabilization: Page Object now waits for dashboard heading and request status after login.
- Regression Protection: `logged_in_page` fixture calls `DashboardPage.expect_loaded()`.
- Status: Documented representative automation failure.
