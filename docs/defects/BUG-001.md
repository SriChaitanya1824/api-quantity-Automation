# BUG-001: Duplicate Registration Error Was Not Displayed in UI

- Type: Representative project defect record, not a historical production incident.
- Severity: Medium
- Priority: High
- Environment: Local React frontend with FastAPI backend.
- Preconditions: User account already exists.
- Steps to Reproduce: Open Register, submit an existing email, observe the page.
- Expected Result: UI displays a clear duplicate-account error.
- Actual Result: Registration failure was not surfaced to the user.
- Evidence: Duplicate registration API returns 409, but the form did not render an alert.
- Logs: API response `{"detail":"Email is already registered"}`.
- Root Cause: Register component awaited API call without a catch block or error state.
- Fix: Add registration error state and render `role="alert"` message.
- Regression Test: `tests/ui/test_registration.py::test_duplicate_registration_shows_error`.
- Status: Fixed in project implementation.
