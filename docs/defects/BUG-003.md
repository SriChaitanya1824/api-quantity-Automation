# BUG-003: API Test Environment Failed Because Postgres Was Unavailable

- Type: Representative project defect record, not a historical production incident.
- Severity: High
- Priority: High
- Environment: Local test shell without Docker.
- Preconditions: Docker/PostgreSQL unavailable.
- Steps to Reproduce: Run API tests against default `DATABASE_URL`.
- Expected Result: Tests run deterministically.
- Actual Result: App cannot connect to Postgres.
- Evidence: Connection failure before endpoint assertions.
- Logs: Database connection refused or Docker command unavailable.
- Root Cause: Tests depended on external runtime services.
- Fix: API tests override FastAPI DB dependency with isolated in-memory SQLite.
- Regression Test: Full `pytest -m api` suite.
- Status: Fixed for API automation; integrated Docker runtime still requires Docker.
